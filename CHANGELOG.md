# Changelog

## 1.1.0

- Support Nova 3, 4 and 5 with automatic selection of Vue Router/Vue 2 or Inertia/Vue 3 assets.
- Extend shared backend constraints to Laravel 8.83.4 through 13, PHP 8.1+ and Carbon 2/3.
- Use script/style APIs compatible with all three Nova majors and native legacy sidebar navigation.
- Preserve GET-only endpoints, Nova authentication, the viewNovaLogs Gate, redaction and scanning bounds.
- Cover both Vue cleanup lifecycles, real Vue runtime rendering and a six-major Laravel CI matrix.

## 1.0.0

- Extract the standalone Nova 5 / Laravel 12 read-only log viewer.
- Include compiled assets, bounded scanning, redaction, recurring diagnostics and safe clipboard formats.
- Document installation, explicit application authorization and configuration.
